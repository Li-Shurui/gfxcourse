# 第 15 课　路径追踪

Whitted 追踪每次反射都走一条确定的射线，漫反射不产生新的漫反射。路径追踪换一个问题：从相机出发，按材质随机走下一条方向，把沿途的光乘起来。很多条这样的路径取平均，就是这个像素的颜色。康奈尔盒是这套估计的标准试纸。

## 你应该看到什么

`output/15_path.bmp` 是一间盒子。左墙偏红，右墙偏绿，地板、天花板和后墙是白的。后墙前方有一块白色的盒子。左前方一颗金属球，右前方一颗玻璃球。天花板上有一块发光的矩形。

红墙的颜色会染到地板和白盒子的左侧，绿墙染到右侧。这是间接光，第 7 课和第 12 课都没有。金属球映出房间。正对相机的那一块往往很暗：它映的是盒子朝相机敞开的那一面，场景的背景是黑的，所以镜子里也是黑的。这不是法线反了。玻璃球能看见后面的盒子被折射，边缘反射更强。

默认是 400×300、每个像素 64 条路径。近看仍有颗粒，这是蒙特卡洛估计的方差，不是纹理。加采样会变干净，也会变慢。`--preview` 用 120×90 和 4 条路径，只用来让测试确认画面不是全黑。

```powershell
.\build\lesson15.exe
.\build\lesson15.exe --preview
```

完整的一帧在这台课程假设的机器上大约几秒。测试跑的是预览。

## 路径怎么走

`trace_path` 维护辐射亮度和吞吐量。吞吐量从白色的 1 开始，每次反弹乘上这一次的材质因子。

漫反射用余弦加权的半球采样。BRDF 是 `albedo / π`，采样密度是 `cosθ / π`，两者相除之后，余弦和 π 消掉，间接光的吞吐量只乘反照率。这个消掉只在「采样密度正好是余弦加权」时成立。换成均匀半球采样却忘了改权重，画面会整体变暗或变亮。

直接光另算。对场景里的面积光随机取一个点，向它连一条阴影线。没被挡住，就加上

```text
brdf * emission * cos_surface * cos_light * (灯的数量 * 面积) / dist²
```

灯的数量出现在分子里，是因为我们先均匀选了一盏灯。`cos_light` 是光线和灯面法线的夹角，灯背对表面时贡献为零。

自发光只在「从相机直接看见」或「经过镜面、玻璃看见」时加进结果。漫反射弹跳之后不再加，否则和直接光采样重复，灯会亮一倍。玻璃不挡住阴影线，和第 12 课一样。

金属沿反射方向走，粗糙度用一个小球里的随机向量去扰动。扰动后若穿进表面，这条路径作废。玻璃按菲涅尔概率只选反射或折射中的一条，不再两条都追。这是和 Whitted 实现的分水岭：路径追踪用随机选择换掉分叉，方差变大，偏差不变。

循环下标从 0 计。下标达到 2，也就是处理完第三次命中之后，才做俄罗斯轮盘：按吞吐量随机终止，活下来的路径把吞吐量除以存活概率。期望不变，很暗的路径不会一直走满 6 次。

单条路径的结果限制在每个通道 16 以内，躲开玻璃聚光造成的个别极亮样本。这会带来一点偏差，换来少一些白点。

## 色调

路径的平均值还是线性辐射亮度，灯的发射可以远大于 1。`tone_map` 先乘曝光 0.85，再对每个通道做 Reinhard：`c / (1 + c)`。然后才编码成 sRGB。不要在色调映射之前截断到 1，否则间接光的层次会没掉。

## 随机数和并行

`Rng` 是 SplitMix64。每个像素一个种子，种子来自像素坐标，所以同一张图可以复现。不要所有像素共用一个生成器再并行，序列会被线程调度打乱，画面每次都不一样，测试也无法比较。

`parallel_rows` 用 `std::jthread` 按行分块。图像的每一行只被一个线程写入。

## 场景

`assets/scenes/cornell.scene`。面积光是天花板上的矩形，发射写在 `area_light` 里，网格上还有一块同位置的自发光四边形，这样相机直接看向灯时有几何可命中。点光源只给光栅器用，这一课的积分不读它。

`sample_direct` 找不到面积光就返回零。把 `area_light` 删掉而只留自发光四边形，房间会非常暗：你只能靠随机路径碰巧打中那一小块灯。

## 跟着代码走

建议顺序：`rng.hpp` 的 `sample_cosine_hemisphere`，`pathtracer.hpp` 的 `sample_direct`，然后 `trace_path` 的三个材质分支，最后 `render_path` 的双重循环。`main.cpp` 只负责加载、计时和「中间一块不能全黑」的检查。

## 运行

先跑默认参数，看颜色渗透和两颗球。再把 `main.cpp` 里的采样数改成 8 看一遍，改成 128 看一遍。构图不变，颗粒变少。若改完采样数颜色整体变了，权重有偏。

## 这一课留下的限制

没有对下一事件和 BSDF 采样做多重重要性采样。玻璃聚光仍然吵。金属的粗糙度不是真正的微表面分布。这些都是第 15 课之后的事，不是这一帧算错了。

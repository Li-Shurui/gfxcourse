# 第 15 课习题

## 拓展阅读

- Kajiya，《The Rendering Equation》，SIGGRAPH 1986。读方程本身和「路径是方程的蒙特卡洛估计」这一句。先不要读完整的证明。
- Shirley，《Ray Tracing in One Weekend》第 7–12 章，以及《Ray Tracing: The Rest of Your Life》的前半。后者解释余弦采样为什么能消掉 π，和俄罗斯轮盘。
- Pharr、Jakob、Humphreys，《Physically Based Rendering》第 13–14 章。本课的直接光是下一事件估计的一个最小版本，书里叫 next event estimation。
- Dutré、Bala、Bekaert，《Advanced Global Illumination》对康奈尔盒照片和模拟的对照。看颜色渗透的方向，不看他们的辐射度算法。
- GAMES101 闫令琪，Lecture 16。

## 编程题

1. 关掉 `sample_direct`，只靠路径碰巧打中灯。用同样的 64 个样本渲染。房间会暗很多，灯的边缘全是颗粒。再打开。这是直接光采样存在的理由。
2. 把余弦采样换成半球上的均匀方向，同时把吞吐量乘上正确的 `cosθ`（均匀密度是 `1/2π`，BRDF 是 `albedo/π`）。画面的亮度应该接近原来。漏乘余弦时，掠射角会过亮。
3. 让自发光在漫反射之后也累加，同时保留直接光采样。灯和灯附近的天花板会亮得不正常。改回去，并在注释里写明两条路径各算了哪一份能量。
4. 把每像素采样数做成命令行参数，例如 `--spp 32`，保留 `--preview` 的默认值。用 16、64、256 各渲染一次，把时间记下来。方差大致按样本数的平方根下降，时间按样本数上升。

## 思考题

金属球正中的黑块，和左墙染到地板上的红，哪一个是 bug 的候选，哪一个是场景和算法的直接结果？分别指出：一条打中黑块的路径看见了什么，一条打中红地板的路径在哪一次反弹捡到了红色。

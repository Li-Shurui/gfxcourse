# 第 7 课　Blinn-Phong 光照

深度测试让近的面挡住远的面。这一课让面自己发光：漫反射决定明暗，高光决定表面上那一块有多亮。使用的是 Blinn-Phong，不是原始 Phong。半角向量比反射向量便宜，而且在掠射角更稳定。

## 你应该看到什么

`output/07_shading.bmp` 里有一个浅色地面、一块偏红的立方体、一颗偏蓝的球。球的上前方有一块高光，背光的一侧沉下去，和地面相接的地方更暗。立方体每个面的亮度不同，因为法线是逐面常数。地面是一块大的四边形，近处亮、远处暗，这是距离衰减，不是雾。

高光应该是一小块，而不是把整个球洗成白色。关键光的强度在 `main.cpp` 里，太大时线性颜色会在 sRGB 编码前就被截断，高光变成死白。

## 模型

`PointLight` 有位置、颜色和强度。到达表面上一点的贡献随距离平方衰减：`intensity / r²`。没有这个衰减时，把灯移远，物体几乎不变亮暗。

`blinn_phong` 对每一盏灯：

```text
l = normalize(light - position)
v = normalize(eye - position)
h = normalize(l + v)
diffuse  = kd * max(n · l, 0)
specular = ks * max(n · h, 0) ^ shininess
```

两者都乘上灯的颜色和衰减，再求和。环境光是一个不依赖方向的常数，避免背光面变成纯黑。它不是真实的间接光。第 15 课才会从别的表面把光弹过来。

`n · l` 为负表示灯在表面背后，漫反射和高光都是零。不要取绝对值，否则立方体的背面会被照亮。

## 几何

`shapes.hpp` 生成立方体、平面和 UV 球。立方体是 `[-1, 1]³` 的六个面，法线指向外侧。球带上下两个极点，极点附近的三角形有两个顶点重合，面积为零。光栅化会跳过它们，不必在生成时特殊处理。

`draw_geometry` 是一个模板。它把模型矩阵作用到顶点上，用法线矩阵作用到法线，再交给第 6 课的裁剪和光栅化。着色器是你传进去的函数，返回线性颜色。

球的位置在 `(0.55, 1, 0.1)`，立方体在左侧并绕 y 轴转了一点。平面是 y = 0 的大四边形。灯在前上方。

## 跟着代码走

先读 `light.hpp` 的公式，再读 `main.cpp` 里那个着色器如何把材质颜色和 `blinn_phong` 乘起来。几何生成可以后看。确认着色器里用的是世界空间的位置和法线，而不是模型空间：灯的位置在世界空间。

## 运行

```powershell
.\build\lesson07.exe
```

把 `shininess` 从几十改成 8，再改成 200。高光变大、变小，形状不应该漂到球的另一侧。漂了，通常是视线方向或半角向量少了一次归一化。

## 这一课留下的限制

颜色是顶点上的常数。下一课从纹理取样。球看起来光滑，是因为法线在三个顶点之间做了插值，不是因为几何很密。靠近看，轮廓仍是折线。

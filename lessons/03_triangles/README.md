# 第 3 课　三角形

光栅化的基本图形不是多边形，是三角形。任意三角形都能用三个边函数回答：这个像素在里面还是外面，如果在里面，它离三个顶点各有多近。

## 你应该看到什么

`output/03_triangles.bmp` 里有三块图形。左边是一个纯色三角形。中间是一个按顶点颜色插值的三角形，三个角的颜色在内部混成渐变。右边是一个矩形，被对角线拆成两个三角形，上半和下半颜色不同，共享边上没有缝，也没有一条明显更亮或更暗的重叠线。

程序启动时还会在一块 4×4 的小图上做覆盖测试：两个三角形拼成正方形，每个像素恰好被涂一次。出现空隙或重叠，这一课失败。

## 边函数

给定有向边 AB 和点 P，

```text
edge(A, B, P) = (B.x - A.x) * (P.y - A.y) - (B.y - A.y) * (P.x - A.x)
```

这是二维叉积。P 在有向边的左侧时结果为正，右侧为负，落在直线上时为零。三个边函数同号，P 就在三角形里。

采样点取像素中心 `(x + 0.5, y + 0.5)`，不取像素角。角点落在共享边上的机会太高，规则会很难稳定。

屏幕的 y 朝下，所以「正面积」的绕序和数学课本里 y 朝上的逆时针不一样。代码不要求调用者背这个绕序：面积为负时，内部测试会交换两条边再判断。返回的重心权重始终对应你传入的顶点顺序。

## 重心坐标

P 对顶点 A 的权重，是 P 与边 BC 组成的三角形面积，除以整个三角形的面积。三个权重相加为 1。都非负时，P 在三角形内（边上的等号下一节处理）。

顶点颜色 `Ca, Cb, Cc` 在 P 处混成 `w0 Ca + w1 Cb + w2 Cc`。这一课的插值是在屏幕空间里做的，没有透视。第 6 课会说明为什么三维里不能再这样混。

## Top-left 规则

两个三角形共用一条边时，边上的像素只能属于其中一个。否则那一行像素会被画两次；如果以后开了混合，颜色就会错。规则是：权重为正，一定在内部；权重为零，只有这条边是「上边或左边」时才算内部。

在 y 朝下的屏幕上，`is_top_left` 的定义是：水平边从右指向左，或者边的终点比起点更靠下。4×4 的自检把这条规则钉死。改它之前先让那一项测试失败一次，看空隙长在哪条边上。

## 这一课留下的限制

三角形在二维屏幕上，顶点不会动。下一课用矩阵把它们转起来。填充仍然没有深度，后画的三角形盖住先画的。

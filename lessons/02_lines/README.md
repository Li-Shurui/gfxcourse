# 第 2 课　直线

## 这一课的目标

屏幕是整数格子。两个端点通常落在格子之间，连线却必须画成一串像素。这一课实现 Bresenham 直线：只用整数加减，决定下一个像素是往右走，还是往右的同时往上（或往下）走。

你不需要浮点除法，也不需要三角函数。这是它的价值。

## 你会看到什么

`output/02_lines.bmp` 的中间是一圈不同斜率的射线，像一颗星。左下有一座用折线画出的小屋。图的四周有一圈边框。

水平线、竖线、45° 线都应该是连续的，不能断成点，也不能在端点多涂一格。

## 算法在决定什么

先把斜率限制在 0 到 1 之间，也就是 `x` 每走一步，`y` 最多走一步。从左端点出发，维护一个误差：理想直线比当前像素中心高出多少，误差就增加多少。误差超过半个像素，`y` 就加一，并把误差减回去。

斜率大于 1 时，交换 `x` 和 `y` 的角色，否则竖线会变成稀疏的点。从右往左画时，先交换端点，或者让步长为 −1。`line.hpp` 把这几类对称写在一层分支里，核心循环只有一种。

端点必须画上。后面的线框立方体、坐标轴和三角形轮廓，都假设 `draw_line(a, b)` 覆盖 `a` 和 `b`。差一个像素，第 5 课的立方体角上就会出现缺口。

## 跟着代码走

`main.cpp` 用第 1 课的 `radians` 生成星形的端点，再用 `draw_line` 把它们连到中心。小屋的顶点是手写的整数坐标，用来覆盖水平、竖直和斜线。

读 `draw_line` 时，先忽略所有对称分支，只看 `|dy| <= |dx|` 且 `x` 递增的那一段。弄懂误差项之后，其余分支都是同一段代码的坐标交换。

## 这一课没有做什么

直线没有宽度，没有抗锯齿，也没有深度。两根线交叉时，后画的直接盖住先画的。下一课用边函数把三角形内部填上。

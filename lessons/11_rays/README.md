# 第 11 课　光线

## 这一课的目标

光栅化从三角形出发，问它盖住哪些像素。光线追踪从像素出发，问这条线先碰到什么。

这一课只碰球体，并用法线给像素上色。能看懂这张图，后面的材质才有落点。

## 你会看到什么

`output/11_normals.bmp` 上有三颗球。颜色是法线映射到 0…1 之后的结果，不是光照：朝右的一侧偏红，朝上偏绿，朝相机偏蓝。三颗球的轮廓是圆，不是折线。球与球重叠时，近的盖住远的。

测试检查画面中心那条射线的方向大致朝向 −z，并且中心像素偏蓝。相机在 +z 看原点时，正前方的法线指向相机，蓝色通道应该明显。

## 射线

```text
point(t) = origin + t * direction
```

`t` 是距离参数。`tmin` 丢掉太近的命中，避免以后阴影射线立刻打到自己身上。`tmax` 是目前最近的命中，更远的不必再记。

`camera_ray` 把像素坐标变回观察射线。图片 `y` 朝下，所以像素的 `v` 越大，射线越朝世界的下方。焦距和视野角决定成像平面有多大。第 5 课用矩阵把点投到像素，这里是那条路的逆：像素生成点，再和眼睛连成线。

## 球

球心 `c`，半径 `r`。把射线上的点代进 `|p - c|² = r²`，得到关于 `t` 的二次方程。判别式小于零是未击中，等于零是擦边，大于零有两个根。取落在 `(tmin, tmax)` 里较小的那个正根。

外向法线是 `(hit - c) / r`。射线从外面进来时，着色用法线等于外向法线；从里面出去时取反，让法线始终面向射线来的那一侧。`Hit::front` 记下是哪一种。玻璃在第 12 课要用这个标志决定折射率的比。

球的 uv 用经纬映射。这一课不用它上色，但命中结构里留着，后面的纹理不用再改 `Hit`。

## 跟着代码走

`ray.hpp` 的 `Ray`、`Hit`、`camera_ray`、`sky_color`。`sphere.hpp` 的 `intersect`。`main.cpp` 放三颗球，对每个像素取最近命中，把法线画出来。没有命中就用背景。

循环是两重的，每个像素一条射线。没有窗口，没有累加。这一课故意慢得可以忽略，好把求交读完。


把一颗球的半径改大，直到它包住相机。中心像素的法线会翻转（`front` 变成 false），颜色跟着变。再移回去。

## 这一课没有做什么

颜色是法线，不是光。没有影子，没有反射。下一课按材质递归。

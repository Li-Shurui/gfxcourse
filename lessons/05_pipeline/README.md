# 第 5 课　相机与线框

## 这一课的目标

矩阵已经能搬动点。这一课决定从哪里看。观察矩阵把世界放进相机坐标系，透视矩阵把近大远小写进裁剪坐标，再投影到第 0 课那张 `y` 朝下的图片上。

到这一课结束，你能从任何位置看一个线框立方体。

## 你会看到什么

`output/05_wireframe.bmp` 是一个白色线框立方体，三条坐标轴从原点画出：红是 `+x`，绿是 `+y`，蓝是 `+z`。立方体近处的边更长。

测试还检查两件和画面无关的事：

- 原点投到 NDC 的中心 `(0, 0)`。
- 相机放在 `(0, 0, 5)`、看向原点时，原点的观察坐标是 `(0, 0, -5)`。它在相机前方，所以 `z` 是负的。

## 观察矩阵

相机由眼睛、目标和上方向组成：

```text
forward = normalize(target - eye)
right   = normalize(cross(forward, up))
up'     = cross(right, forward)
```

`view_matrix` 的第一行是 `right`，第二行是 `up'`，第三行是 `-forward`。第三行那个负号，就是「看向 −z」。一个在眼睛正前方的点，观察空间的 `z` 是负数，后面的深度测试和透视都按这个符号来。

平移项是行向量与眼睛的点积，带符号。它把眼睛自己送到原点。你可以用测试里的那个点手算一遍。

## 透视

`perspective` 是 OpenGL 的那一种：竖直视野角、宽高比、近平面、远平面。近平面映到 NDC 的 `z = -1`，远平面映到 `z = +1`。

矩阵必须从 `Mat4::zero()` 开始。右下角是 0，不是单位矩阵的 1。漏掉这一点时，裁剪坐标的 `w` 会多出一个 1，除以 `w` 之后远处和近处挤在一起，线框看起来像正交投影，近平面裁剪也会切错。

投影到像素：

```text
ndc = (clip.x / clip.w, clip.y / clip.w)
x   = (ndc.x + 1) * 0.5 * width
y   = (1 - (ndc.y + 1) * 0.5) * height
```

`y` 的那个 `1 -`，把 NDC 的「上」翻到图片的「上」。世界 `y` 朝上，图片 `y` 朝下，只在这一行交换。

`clip.w` 必须是正的。点在相机背后时，`w` 可以变号，直接除会把点投到画面另一侧。线段用 `clip_line_near` 在平面 `z + w = 0` 上裁一刀；两端都在后面就整段丢掉。

屏幕上的线再经过 Cohen–Sutherland 裁到窗口矩形里，最后才调用第 2 课的 Bresenham。裁剪在浮点里做，光栅化在整数里做。

## 跟着代码走

`camera.hpp` 是这一课的全部数学。`screen_line.hpp` 只负责窗口裁剪后调用 `draw_line`。`main.cpp` 先跑两个断言，再把立方体的 12 条边和三根轴送进这条管线。

立方体的顶点在模型空间。这一课的模型矩阵是单位矩阵，所以世界坐标就是那些顶点。

线框没有面，更没有谁挡住谁。下一课给每个像素一个深度，并开始填三角形。

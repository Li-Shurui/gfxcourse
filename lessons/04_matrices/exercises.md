# 第 4 课习题

## 拓展阅读

- GAMES101 闫令琪，Lecture 3–4。重点是齐次坐标为什么能表示平移，以及法线矩阵为什么要逆转置。
- Shirley，《Fundamentals of Computer Graphics》第 6 章，刚体变换与缩放。
- Scratchapixel，《Geometry》。对照 Rodrigues 公式和本课 `Mat4::rotation`。

## 编程题

1. 打印 `T * R * S` 和 `S * R * T` 作用在点 `(1, 0, 0)` 上的结果。选一个不是零的平移。用一两句话写出这两个点分别相对原点在哪里。
2. 实现绕 x 轴 90° 的测试：`(0, 1, 0)` 应该到 `(0, 0, 1)`。右手系，拇指指向 +x，四指从 +y 转向 +z。
3. 给一个已知逆矩阵的变换，例如先平移 `(3, -2, 5)` 再绕 y 轴 90°。用 `inverse` 乘回去，三个分量的误差都要小于 `1e-4`。高斯消元写错时，通常是某一列变成了另一列。
4. 把五边形换成你自己的折线，给它一个会随时间变化的角度。这一课没有窗口，用一个循环写出 8 张 BMP，角度从 0° 到 315°。用看图软件连着翻，确认枢轴没有漂。

## 思考题

单位矩阵的逆是它自己。零缩放的矩阵没有逆。场景里如果有人把某个轴的缩放写成 0，`normal_matrix` 应该失败还是返回一个约定的值？本课的实现会怎样，读 `inverse(Mat3)` 之后回答。

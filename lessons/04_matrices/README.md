# 第 4 课　矩阵

## 这一课的目标

物体要能平移、旋转、缩放，而且这三件事要能叠在一起。这一课实现 3×3 和 4×4 矩阵。齐次坐标让平移也变成乘法，这样模型、相机、投影才能连成一条链。

## 你会看到什么

控制台先跑测试。它们检查三件事：

- 绕 `y` 轴正 90°，把 `(1, 0, 0)` 送到 `(0, 0, -1)`。
- 平移再乘它的逆矩阵，回到原点附近。
- 非均匀缩放 `(2, 1, 1)` 的法线矩阵，把 `(1, 1, 0)` 送到大约 `(0.5, 1, 0)`。

`output/04_matrices.bmp` 上有两个五边形。一个保持原样，另一个经过平移、旋转和缩放。形状是同一个，位置和朝向变了。

## 存储和乘法

`Mat4` 的 16 个数按列放进数组，下标是 `col * 4 + row`。`operator()(row, col)` 用行、列访问，和数学写法一致。向量是列向量，变换写成 `v' = M * v`。

不要用 `Mat4{}` 表示零矩阵。成员默认值把它初始化成单位矩阵。需要全零时调用 `Mat4::zero()`。第 5 课的透视矩阵如果从单位矩阵改几个元素，右下角会留下一个错误的 1。

`Mat3` 用三个列向量表示。它主要服务于法线，不负责带平移的点。

## 变换的顺序

缩放、旋转、平移分别是 `Mat4::scale`、`rotation`、`translation`。旋转用 Rodrigues 公式，轴不必事先是单位向量，函数里会归一化。

连续变换写成 `T * R * S`。乘法从右边先作用到向量上，所以点先被缩放，再旋转，再平移。倒过来写也是合法的矩阵，但意思变成「在已经平移之后的位置上缩放」，物体会离开你想要的枢轴。第 10 课的场景节点用的就是 `T * Ry * S`。

## 逆矩阵和法线

`inverse(Mat4)` 用高斯消元。测试里把 `M * inverse(M)` 和单位矩阵比较，允许一点浮点误差。

法线不能用旋转缩放矩阵直接变换。球被压扁以后，几何上垂直于表面的方向，不是把原来的法线也压扁。正确的是用法线矩阵：模型矩阵左上 3×3 的逆，再转置。`normal_matrix` 做这件事。

非均匀缩放 `(2, 1, 1)` 把 `x` 拉长。原来斜着的法线 `(1, 1, 0)` 在拉长后的表面上应该更偏向 `y`，也就是 `x` 分量变小。测试期望的方向是 `(0.5, 1, 0)`。如果你的逆矩阵把行和列放反，这一项会先失败，画面上则是光照朝向奇怪的一面。

## 跟着代码走

`mat.hpp` 里，`transform_point` 和 `transform_vector` 只在类里声明，定义写在 `operator*(Mat4, Vec4)` 之后。成员函数的函数体如果写在类内，会在类结束时就被编译，那时自由函数形式的乘法还看不见。这是 C++ 的规则，不是矩阵的规则。

`main.cpp` 前半是断言，后半把一个二维多边形的顶点当成 `z = 0` 的点，乘上矩阵，再用第 2 课的直线画出来。

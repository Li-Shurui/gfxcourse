# 第 1 课习题

## 拓展阅读

- GAMES101 闫令琪，Lecture 2–3 的向量部分。对照本课的 `dot`、`cross`、`normalize`。
- Scratchapixel，《Reflection, Refraction and Fresnel》。重点看入射向量的方向约定：有的教材让入射向量指向眼睛，本课让它指向表面。符号差一个负号，公式就不能混抄。
- Pharr、Jakob、Humphreys，《Physically Based Rendering》第 8 章里关于 `Reflect` 与 `Refract` 的两页。先不要读整章积分。

## 编程题

1. 在 `main.cpp` 里加一组测试：`reflect` 作用两次回到原方向，长度保持不变。用 `nearly` 比较，不要用 `==`。
2. 验证斯涅尔定律的一个特例。空气到玻璃，`eta = 1/1.5`，入射方向 `(0, -1, 0)`，法线 `(0, 1, 0)`。透射方向应该几乎朝下，并且是单位向量。再把入射角改到接近 90°，确认函数在某个角度开始返回 false。把这个临界角和 `asin(1/1.5)` 对一下。
3. 用第 0 课的 `Image` 画一个单位圆，从圆心画出 `reflect` 前后的两根向量。入射方向在圆上转一圈。图应该关于法线对称。
4. 实现 `refract` 的一个错误版本：忘记在全反射时返回 false，仍然写出一个方向。用你的测试抓住它。然后改回正确版本。

## 思考题

菲涅尔反射率在入射角为 0 时大约是 `((n-1)/(n+1))²`。玻璃 n = 1.5 时这个值是多少？为什么路径追踪里一块正对相机的玻璃仍然「有一点」反射，而不是完全透明？

# 第 1 课　向量

三角形、相机、光线、法线，最后都是三个浮点数。这一课把它们收成 `Vec2`、`Vec3`、`Vec4`，并把后面光线追踪会原样用到的反射、折射和菲涅尔系数先算对。

## 你应该看到什么

控制台打印一组通过或失败。失败时进程返回非零，`ctest` 会抓住它。同时 `output/01_vectors.bmp` 上有一束从中心指出去的箭头，用来确认你画的方向和角度一致，而不是只在断言里自我循环。

## 点积和叉积

点积 `a · b = |a||b|cosθ`，代码里就是三个分量相乘再相加。它回答两个问题：两个方向有多接近，以及一个向量在另一个方向上的投影有多长。光照里的 `max(n · l, 0)` 就是从这里来的。

叉积 `a × b` 同时给出方向和面积。方向用右手定则：从 a 转向 b，拇指是结果。长度等于以 a、b 为边的平行四边形面积。二维的「叉积」退化为一个数，就是这个面积的带符号版本。第 3 课的边函数就是它。

单位向量用 `normalize`。零向量不能归一化，调用方要保证长度不是零。课程里的相机、法线和光线方向在归一化之前都有这个前提。

## 反射

入射方向 `i` 指向表面（从眼睛或上一击来），法线 `n` 是单位向量，指向入射的那一侧。反射方向是

```text
reflect(i, n) = i - 2 (i · n) n
```

若 `i` 已经指向外侧、`n` 与它对着，点积为负，减号会把法线方向上的分量翻过去。自己在纸上画一根斜着撞上水平面的箭头，再对 `vec.hpp` 里的 `reflect` 代一组数字。第 1 课的测试就是这样钉死符号的。后面无论是光栅高光还是光追，都调用这一个函数，不再各写一套。

## 折射

`refract(i, n, eta, out)` 的 `eta` 是 η入射 / η透射。从空气进玻璃，大约是 1 / 1.5。斯涅尔定律在向量形式里先算平行于表面的分量，再看剩余的长度够不够法线方向。不够就是全反射，函数返回 false，调用方只能反射。

第 12 课的玻璃和第 15 课的路径追踪共用这个实现。现在就把全反射的返回值当成控制流，而不是把一个 NaN 方向传下去。

## 菲涅尔

介质交界上，反射掉多少能量、透射多少，取决于入射角和两侧折射率。`fresnel_dielectric` 使用 Schlick 之外的精确电介质公式：先算两侧的余弦，再合成 s 和 p 偏振的反射率。垂直看一块玻璃，大约只有 4% 被反射；掠射时反射率趋近 1。这就是玻璃球边缘发白、中间能看穿的原因。

## 跟着代码走

`vec.hpp` 是头文件，几乎全是 `constexpr`。分量乘法 `operator*` 是逐分量的，给颜色和缩放用。把它和点积弄混是后面最常见的笔误：点积返回 `float`，颜色相乘返回 `Vec3`。

`gray(v)` 得到 `(v, v, v)`。写成 `Vec3{v}` 会得到 `(v, 0, 0)`，也就是纯红。第 4 课之后的默认高光、背景和清屏都经过这个区别。

`check.hpp` 的 `GFX_CHECK` 在失败时打印表达式和左右两个值。测试故意放在 `main.cpp` 里，而不是另建框架：你改了 `reflect`，重新运行这一课就能看到哪一条断言先坏。

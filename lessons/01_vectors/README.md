# 第 1 课　向量

## 这一课的目标

三角形、相机、光线、法线，到最后都是三个浮点数。这一课把它们收成 `Vec2`、`Vec3`、`Vec4`，并把后面光线追踪会原样用到的反射、折射和菲涅尔系数先算对。

你不会看到一张新「作品」，但会看到一组测试通过。从这一课开始，程序自己检查自己。

## 你会看到什么

控制台打印一串「通过」。任何一条失败，进程就返回非零，`ctest` 会抓住它。

同时 `output/01_vectors.bmp` 上有一束从中心指向不同方向的箭头。它用来确认你画的方向和角度是一致的，而不是只在断言里自我循环。

## 点积和叉积

点积：

```text
a · b = a.x*b.x + a.y*b.y + a.z*b.z = |a||b| cosθ
```

它回答两个问题：两个方向有多接近，以及一个向量在另一个方向上的投影有多长。第 7 课光照里的 `max(n · l, 0)` 就是从这里来的。

叉积 `a × b` 同时给方向和面积。方向用右手定则：四指从 a 转向 b，拇指是结果。长度等于以 a、b 为边的平行四边形面积。二维的「叉积」退化为一个数，就是这个面积的带符号版本。第 3 课的边函数就是它。

单位向量用 `normalize`。零向量不能归一化，调用方要保证长度不是零。课程里的相机方向、法线和光线方向，归一化前都满足这一点。

## 反射

入射方向 `i` 指向表面，法线 `n` 是单位向量，指向入射来的那一侧。反射方向是：

```text
reflect(i, n) = i - 2 (i · n) n
```

若 `i` 朝表面而来，`n` 与它对着，点积是负的，减号会把法线方向上的分量翻过去。自己在纸上画一根斜着撞向水平面的箭头，再对 `vec.hpp` 里的 `reflect` 代一组数。这一课的测试就是这样钉死符号的。后面无论是光栅高光还是光追，都调用这一个函数，不再各写一套。

## 折射

`refract(i, n, eta, out)` 的 `eta` 是入射侧折射率除以出射侧折射率。从空气进玻璃，大约是 `1 / 1.5`。斯涅尔定律在向量形式里先算平行于表面的分量，再看剩下的长度够不够法线方向。不够就是全反射，函数返回 `false`，调用方只能反射。

第 12 课的玻璃和第 15 课的路径追踪共用这个实现。现在就把全反射的返回值当成控制流，而不是把一个不存在的方向传下去。

## 菲涅尔

介质交界上，反射掉多少能量、透射多少，取决于入射角和两侧折射率。`fresnel_dielectric` 用精确的电介质公式：先算两侧余弦，再合成两种偏振的反射率。垂直看一块玻璃，大约只有 4% 被反射；掠射时反射率趋近 1。这就是玻璃球边缘发白、中间能看穿的原因。

## 跟着代码走

`vec.hpp` 是头文件，几乎全是 `constexpr`。

分量乘法 `operator*` 是逐分量的，给颜色和缩放用。它和点积不是一个东西：点积返回 `float`，颜色相乘返回 `Vec3`。这是后面最常见的笔误。

`gray(v)` 得到 `(v, v, v)`。写成 `Vec3{v}` 得到的是 `(v, 0, 0)`，也就是纯红。第 4 课之后的默认高光、背景和清屏都会经过这个区别。

`check.hpp` 的 `GFX_CHECK` 在失败时打印表达式和左右两个值。测试放在 `main.cpp` 里，不另建框架：你改了 `reflect`，重新运行这一课就能看到哪一条先坏。

# 第 13 课　三角形相交

## 这一课的目标

球的二次方程不能表示环面和房间。这一课用 Möller–Trumbore 算法让射线和三角形相交，再把第 12 课的 Whitted 追踪接到网格上。

每个命中都要扫过全部三角形，所以它慢。加速在下一课。

## 你会看到什么

`output/13_mesh_ray.bmp` 里，一块棋盘格地面上悬浮着一枚金色环面，旁边一颗红色的漫反射球。环面是金属，能映出地面的格子和天空。它在地面上有影子。红色球也有影子，并且会出现在金属的反射里。背景是浅浅的天空，不是纯黑。

环面来自三角形，轮廓是折线。洞是几何上的洞：透过洞应该看见地面或天空，而不是一块补上的多边形。相机放得略高，环面会显得扁，这是视角，不是把圆环压扁了。

默认分辨率 360×270。暴力遍历几千个三角形、再加上反射，这一课大约要数秒到十几秒。它比前面的课慢，是这一课的内容，不是构建开错了优化。

## Möller–Trumbore

三角形三个顶点 `v0, v1, v2`。射线 `origin + t direction`。算法用 `v0` 到另外两个顶点的边，以及射线方向，做三次标量三重积，直接得到 `t` 和重心坐标 `u, v`，不必先算平面方程再判断内外。

`det` 接近零表示射线和三角形平行，没有交点。`u`、`v` 小于零或 `u + v` 大于 1，交点在三角形外。`t` 必须落在 `(tmin, tmax)` 里。

重心权重 `w = 1 - u - v` 对应 `v0`，`u` 对应 `v1`，`v` 对应 `v2`。法线和 uv 用这三个权重插值。插值后的着色法线要翻到面对射线的那一侧，和球的约定一致。几何法线（三角形平面的法线）单独保存。玻璃的折射用法线时应该用几何法线。平滑着色法线不是任何一张真实的平面，用来折射会把光线折进表面里面。

## 世界

`RWorld::from_scene` 把场景里的网格变到世界空间：顶点乘模型矩阵，法线乘法线矩阵。场景对象必须比 `RWorld` 活得久，世界里只留了指针和已经变换好的三角形。

`closest_hit` 先测所有的球，再扫所有三角形，留 `t` 最小的命中。阴影测试跳过电介质。未命中时，若场景打开了天空就用天空颜色，否则用背景。

`assets/scenes/torus.scene` 描述这一课的构图。两盏点光源，一盏偏暖，一盏偏冷，避免金属只反射一片均匀的天空、看起来像一个扁盘子。

## 跟着代码走

`trimesh.hpp` 的 `intersect_triangle`。`world.hpp` 的 `from_scene` 和 `closest_hit`。`main.cpp` 加载环面场景，调用第 12 课的 `render_whitted`，并打印三角形数量和耗时。

## 自己跑一次

```powershell
.\build\lesson13.exe
```

把环面的缩放临时加倍。耗时大约跟着三角形数线性增长——这一课三角形数不变，缩放不增加三角形，所以时间差不多。下一课才会让你看见「换了数据结构，同一张图，时间不一样」。

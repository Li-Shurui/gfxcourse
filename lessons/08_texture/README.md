# 第 8 课　纹理

## 这一课的目标

到上一课为止，一个三角形上的颜色来自顶点。纹理把颜色存在另一张图里，再用 uv 去查。这一课并排比较两种查法：最近邻和双线性。

采样在线性光下进行，因为纹理文件里存的是 sRGB。

## 你会看到什么

`output/08_texture.bmp` 是两面墙，贴的是同一张蓝白棋盘。左边一块一块，斜边上有明显的阶梯，这是最近邻。右边同一张棋盘被抹开，格子的边界是过渡，这是双线性。两面墙都绕竖直轴转了大约 18°，所以你看到的不是正对相机的矩形，透视会把远处的格子压扁。

如果双线性看起来像一堆星形或灰泥，而不是软化的方格，通常是格子只有一个像素。一个像素宽的棋盘格在双线性下会和邻居混成中间色，再被透视拉斜，形状就散了。本课的格子是 8×8 个纹素。

## 两套坐标

纹理坐标 `u` 向右、`v` 向上，和 OBJ 一致。图片的 `y` 向下。`Texture::sample` 在取样前做 `v = 1 - v`。漏掉这一步时，第 9 课之后所有模型的贴图都会上下颠倒，而这一课手写的墙可能看起来仍「差不多」，因为棋盘格上下对称。

`u`、`v` 先减去各自的 `floor`，落回 `[0, 1)`。超出 0 到 1 的坐标因此重复。平面的 uv 可以大于 1，用来把一张砖贴很多遍。

## 最近邻和双线性

最近邻取离采样点最近的纹素。它快，边缘硬，斜着看时会跳。

双线性取周围四个纹素，按小数部分做两次线性插值。采样位置要减去半个纹素：`u * width - 0.5`。不减的话，插值中心落在纹素的角上，格子会整体偏半个像素，和最近邻并排时对不齐。

四个纹素用 `fetch` 读取。它先按宽高取模，允许坐标暂时是负数，再把 sRGB 解码成线性 `Vec3`。插值发生在线性空间。如果在编码后的字节上插值，蓝和白的中间会偏暗。第 6 课的传输函数就是为了避免这个。

## 跟着代码走

`texture.hpp` 的 `sample` 和 `make_checker`。`main.cpp` 生成 4×4 个格子、每格 8 个像素的棋盘，建两面绕 `y` 轴转动的四边形，左边设 `Filter::Nearest`，右边用默认的双线性。

着色器仍然是第 7 课的 Blinn-Phong，只是漫反射颜色换成了 `texture.sample(frag.uv)`。墙的 uv 要在几何里写好。四边形四个角是 `(0,0)`、`(1,0)`、`(1,1)`、`(0,1)` 这一类，不要四个顶点都写成 0。

## 这一课没有做什么

纹理是程序生成的。下一课从 OBJ 文件读网格，uv 由模型带来。还没有 mipmap。缩得很小的棋盘会闪，这是预料之中的。第 10 课的地面如果离相机很远，你会再见到它。

# 第 14 课　层次包围盒

## 这一课的目标

第 13 课对每个三角形做测试。大多数三角形和这条射线毫无关系。层次包围盒（BVH）先用一个盒子包住很多三角形，射线没碰到盒子就整枝跳过。

这一课要求跳过之后的图像和暴力遍历相同，并且在场景还不小的时候更快。

## 你会看到什么

`output/14_bvh.bmp` 是一颗蓝色的球和地面。球来自三角网格，不是第 11 课的解析球。地面是一块四边形。构图为了把时间花在三角形上，相机离得比较近，地面可能只露出一条。

程序把同一批三角形用两种方法各画一遍。像素差别超过阈值就失败。暴力遍历如果已经花了明显的时间，而 BVH 更慢，也失败。很小的场景上，建树和遍历的常数会盖过收益，所以「BVH 比较慢」只在暴力遍历本身已经不便宜时才算错。

测试使用 `--preview`：更低的分辨率、更少的细分。自己看图时不要加这个参数，球的轮廓会细一些。

```powershell
.\build\lesson14.exe
.\build\lesson14.exe --preview
```

## 盒子

轴对齐包围盒由两个角点组成。射线和盒子相交是三对平面的区间交：每一维算出进入和离开的 `t`，三个区间都重叠才算碰到。方向分量接近零时不能除，改成「原点不在这对平面之间则错过」。

盒子只用于丢弃。真正的交点仍然来自三角形测试。所以 BVH 不会改变画面，只会少做测试。一旦画面和暴力遍历不同，就是漏了节点、`t` 区间写反，或者叶子里的三角形下标错了。

## 怎么建

每个三角形用三个顶点的包围盒，再取中心。沿包围盒最长的那一根轴，按中心的中点切开。一边一个子节点。叶子里最多四个三角形，不再往下分。

节点存在一个数组里，子节点用下标，不用指针。`vector` 在 `push_back` 时会搬家，指向节点的指针会失效。这是这一课最容易出现、也最难从画面上看出的错误：有时能画，有时只画出一半。

遍历用显式栈，不递归。射线先碰父盒子，再碰两个孩子。孩子的进入距离已经大于当前最近的三角形命中时，那个孩子可以不进。

## 场景里谁走 BVH

`hit_scene` 先用解析方法测球，再用 BVH 测三角形。球只有几个，建进树里省不下多少，还会把「球」和「三角形」混成一种图元。这一课的演示场景可以没有解析球，全是三角形。

## 跟着代码走

`bvh.hpp` 的 `Aabb::hit`、`Bvh::build`、`Bvh::closest`。`main.cpp` 生成一颗 UV 球和一块地面，计时两种算法，并逐像素比较。

## 自己跑一次

先跑不带 `--preview` 的版本，看控制台打印的两个时间。再把球的经纬分段提高。暴力遍历的时间大致线性变长，BVH 变长得更慢。图像仍应一致。

## 这一课没有做什么

划分用的是中点，不是表面积启发式（SAH）。三角形大小差很多时，这棵树会不平衡。它已经足够把下一课的路径追踪从「每个像素扫整个房间」里救出来。

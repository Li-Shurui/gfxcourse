# 第 16 课习题

## 拓展阅读

- Pharr、Jakob、Humphreys，《Physically Based Rendering》第 1 章的两张图：光栅化管线和路径追踪各解决渲染方程的哪一部分。
- Akenine-Möller 等，《Real-Time Rendering》第 1 章对「实时」的定义。本课的左边离实时还差一个数量级的工程，但公式已经是那条线上的。
- Shirley，《Ray Tracing in One Weekend》整本再翻一遍。你现在能指出他没有做、而这门课做了的部分（网格、BVH、场景文件、光栅器），以及他做了、这门课没做的部分（景深、可移动相机的散焦）。
- 康奈尔大学 Program of Computer Graphics 公开发表的盒子照片。和你的右边比颜色渗透的方向，不要比噪声和白平衡。

## 编程题

1. 在对比图的中间间隔上写两个标签画不进 BMP 的文字。改成在左边图的左上角涂一条红，右边图涂一条绿，避免两张图拼反了自己看不出来。用像素坐标，不要引入字体库。
2. 给 `lesson16` 加 `--spp`。固定其余参数，用 4、16、64 渲染三张对比图。左边不应该随 spp 变化。若左边变了，说明你不小心让光栅器也读了随机数。
3. 把解析球从路径追踪里拿掉，改成加载一颗细分过的球网格，让两边的球都是三角形。轮廓会接近。记录路径追踪变慢了多少，并说明慢在求交，不在着色。
4. 选做其一：给光栅器加阴影贴图，或给路径追踪加多重重要性采样。只做一种，并在 `exercises` 的笔记里写你没有做另一种的原因。做完用这一课的对比图当验收。

## 思考题

如果把点光源从场景里删掉，只留面积光，左边会变成什么样，右边会变成什么样？反过来，删掉面积光、只留点光源呢？用你对两个渲染器各自读取哪些字段的理解来答，不必先改文件。改文件是用来核对答案的。
